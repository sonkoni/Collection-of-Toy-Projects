# VoyagerX [Vrew/vFlat] iOS 개발자 자격요건

## 회사(VoyagerX)에서 요구하는 자격 요건과의 부합성

**A. 모든 개발자 공통 요건**

- **개발을 좋아함:** 저는 개발 과정에서 문제를 해결하고 새로운 기능을 구현하는 것을 즐깁니다.
- **수학을 좋아함:** 수학교육과 출신으로 논리적 사고와 분석 능력을 통해 개발에 임하고 있습니다.
- **딥러닝에 관심이 많음:** 딥러닝 기술에 흥미를 느끼고, 이를 학습하여 적용할 방법을 모색하고 있습니다.
- **협업이 두렵지 않음:** 다양한 프로젝트에서 팀원들과의 협업 경험이 많아, 협업을 두려워하지 않습니다.
- **책임감이 강함:** 프로젝트의 성공과 팀의 목표 달성을 위해 항상 책임감을 가지고 일합니다.

**B. 앱 개발자 공통 요건**

- **앱 개발에 보람을 느낌:** 사용자가 만족하는 앱을 개발했을 때 큰 보람을 느낍니다.
- **1px 어긋난 것이 자꾸 눈에 밟힘:** UI의 작은 디테일도 놓치지 않으려 노력합니다.
- **동작이 부드럽지 않으면 고치고 싶음:** 앱의 퍼포먼스 개선에 지속적인 관심을 가지고 있습니다.
- **더 빨리 더 잘 만들 수 없을까 고민함:** 효율적인 코드 작성과 최적화 방법을 끊임없이 고민합니다.
- **완벽만큼 완성을 중요하게 생각함:** 완벽한 결과물을 추구하면서도, 프로젝트를 적시에 완료하는 것 또한 중요하게 생각합니다.

**C. 앱 개발자 공통 기술 질문**

- **PNG와 JPG의 차이점:** PNG는 무손실 압축을 지원하며, 투명도를 유지할 수 있습니다. JPG는 손실 압축을 사용하며, 주로 사진에 적합합니다.
- **Dynamic Programming이란:** 문제를 부분 문제로 나누어 해결하고, 이를 저장해 반복 계산을 줄이는 방법입니다.
- **Virtual Memory란:** 실제 물리적 메모리보다 큰 메모리 공간을 사용할 수 있게 하는 메모리 관리 기법입니다.
- **Garbage Collection이란:** 자동으로 메모리에서 더 이상 사용되지 않는 객체를 정리해 주는 메모리 관리 기법입니다.
- **Cache란:** 데이터 접근 시간을 줄이기 위해 자주 사용하는 데이터를 임시로 저장해두는 메모리 공간입니다.

**D. iOS 개발자 기술 질문**

- **Auto Layout의 장단점:** Auto Layout은 다양한 화면 크기에서 일관된 UI를 유지할 수 있게 해주지만, 복잡한 레이아웃의 경우 성능 문제가 발생할 수 있습니다.
- **MVC 패턴이란:** Model-View-Controller 패턴은 데이터와 사용자 인터페이스를 분리하여 유지보수를 용이하게 합니다.
- **KVC와 KVO란:** KVC는 Key-Value Coding으로 객체의 속성에 접근하는 방법이며, KVO는 Key-Value Observing으로 속성 변경을 관찰하는 메커니즘입니다.
- **Swift의 특징은:** Swift는 안전성, 성능, 표현력을 모두 고려한 현대적인 언어로, 타입 추론과 옵셔널, 함수형 프로그래밍 요소를 포함하고 있습니다.
- **Higher Order Function이란:** 함수를 인수로 받거나, 결과로 함수를 반환하는 함수입니다.
- **Method Swizzling이란:** 런타임에서 메서드의 구현을 동적으로 바꾸는 기술입니다.
- **HTTP/2의 특징은:** 멀티플렉싱, 헤더 압축, 서버 푸시 등을 지원해 성능을 개선합니다.
- **Memory Leak의 대처방법은:** ARC를 활용해 강한 순환 참조를 피하고, 메모리 프로파일러를 사용해 누수를 추적합니다.
- **이미지 리스트의 성능 향상법은:** 이미지 캐싱, 비동기 로딩, 압축된 형식 사용 등을 통해 성능을 향상시킬 수 있습니다.
